# archive

Dated records from earlier builds of rule-architect, kept in the language they were
written in. They are **not** part of the current contract and must not be cited as
one — `SKILL.md` is the only source of truth for what the skill does today.

Known drift in these files:

- `design-2026-07-15.md` lists `NAMING_CONVENTIONS.md` as an always-generated doc and
  a "Quick Reference" table in CLAUDE.md. The current contract generates `PITFALLS.md`
  and a Routing table instead.

Decisions taken after this point are recorded as ADRs in `docs/adr/`.
